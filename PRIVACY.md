# Privacy Policy

My Affiliate Tags handles all saved tag keys, descriptions, URLs, and access timestamps in `chrome.storage.local` in the user's browser. This data is not sent to the extension author or to an external service.

The extension reads the URLs of tabs and completed main-frame navigation on supported Amazon domains only to detect the `tag` query parameter and update the local saved-tag list and badge. It does not collect passwords, cookies, payment information, form contents, or browsing history.

Opening a saved URL sends navigation to that URL in Chrome. Amazon and other websites may independently apply their own privacy policies and set cookies under their control.

The user can delete individual records or all saved records from the extension options page. Exported JSON files are created locally and remain under the user's control.

There are no analytics, advertising networks, remote APIs, or third-party scripts in the extension. The extension's source code and updates are governed by this repository.
